Privacy & Security

Adblocked AI hides ads on ChatGPT. We built it so that we never receive any of your data. There is no account, no analytics, and no server for your data to go to.

The Browser Extension

What it stores

The extension keeps a few things in your browser’s local extension storage:

  • whether blocking is turned on or off
  • your whitelist, the sites you’ve added in Settings where blocking is turned off
  • how many ads it has hidden, in total and per site (for example, chatgpt.com)

This data stays on your device. It is not synced to your browser account and never sent to us or anyone else. You can reset the counter in Settings, and removing the extension deletes all of it.

What it does on ChatGPT

The extension only runs on chatgpt.com. There, it adds a style rule that hides known ad elements and counts how many it hid. It does not read, store, or send your conversations or anything else on the page.

What it never does

  • It makes no network requests. The blocking rules are bundled inside the extension.
  • It collects no analytics, browsing history or usage data.
  • It does not load or run code from the internet.

Permissions

Storage
To save the settings and counts listed above.
Access to chatgpt.com
To hide ads on ChatGPT pages. It has no access to any other site.

This Website

The adblocked.ai site is a static site with no analytics, no cookies and no third-party scripts or fonts. If you switch to dark mode, that choice is saved in your browser so the site remembers it; it is never sent to us.

The site is hosted on GitHub Pages. GitHub, as the host, may log visitors’ IP addresses for security purposes under its own privacy statement. We do not receive or use those logs.

Security

Don’t take our word for it. Unlike the AI it works on, adblocked.ai lets you view source. The extension is open source under the MIT license, so anyone can check that it does what this page says: github.com/blockerpunks/adblocked.ai-plugin (opens in a new tab)

The extension’s Settings page shows its version and the exact code commit it was built from, so you can match your installed copy against a public release.

Changes

If we ever add a feature that sends data anywhere, it will be described here before it ships, and this page’s date will change.
